# yt_summary_bot

Discord-бот: находит YouTube-ссылки в сообщениях, создаёт под ними тред и
постит туда тезисное саммари видео — по субтитрам, через LLM
(любой OpenAI-совместимый API).

## Возможности

- **Автоматические треды** под каждым сообщением с YouTube-ссылкой
  (watch / shorts / live / embed / youtu.be), повторные ссылки не дублируются.
- **Прогрессивный разбор** — читатель сам решает, глубже ли читать:
  1. **Кратко** — суть в 1–2 строки (+ пояснение простым языком для сложных тем);
  2. **Тезисы** — 5–9 пунктов;
  3. **Подробно** — по разделам видео с кликабельными таймкодами.
  4. **Обзор автора** — кто такой, чем занимается, доверять ли; кешируется
     по каналу (~90 дней, обновляется в фоне, пользователь не ждёт).
- **Надёжность**: очередь задач (не более одного LLM-запроса одновременно),
  ретраи при лимитах API (429 с `Retry-After`) и сетевых сбоях,
  персистентный буфер недоставленных сообщений (SQLite) — досылает автоматически.
- **Кеш разборов**: разобранное видео сохраняется в SQLite (`bot_data.sqlite3`);
  повторная ссылка отвечает мгновенно, без качания субтитров и LLM-вызова.
  Старый `pending_replies.json` мигрирует в БД автоматически при первом старте.
- **Заточено под Discord**: GFM-таблицы конвертируются в буллеты,
  длинные ответы режутся на сообщения с сохранением код-блоков и метками `(1/N)`.
- Промпты и тексты ошибок — в [`prompts.yaml`](prompts.yaml), без правок кода.

> Развитие: обобщение на любые ссылки (статьи, сайты), разбор по блокам
> «кратко → тезисно → подробно с таймкодами → обзор автора», база разобранных
> источников и авторов — план в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт

### Локально (Windows)

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
copy .env.example .env   :: заполнить токены (см. ниже)
.venv\Scripts\python yt_summary_bot.py
```

(или просто `start.bat` при готовом `.venv`)

### Docker (домашний сервер, рекомендованный способ)

```bash
cp .env.example .env   # заполнить токены
docker compose up -d --build
```

При старте контейнера `entrypoint.sh` делает `git pull` — обновление бота
сводится к `docker compose restart`. ⚠️ При этом **локальные правки кода в
примонтированной папке затираются** (`git reset --hard origin/main`).

## Настройка Discord-приложения

1. [Discord Developer Portal](https://discord.com/developers/applications) →
   New Application → Bot → **Reset Token** → это `DISCORD_BOT_TOKEN`.
2. Вкладка Bot → включить **Message Content Intent** (без него бот не видит
   ссылки в сообщениях).
3. OAuth2 → URL Generator: scopes `bot`, права:
   **View Channels, Send Messages, Create Public Threads, Send Messages in
   Threads, Read Message History**.
4. Пригласить бота по сгенерированной ссылке на свой сервер.

## Переменные окружения (.env)

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `DISCORD_BOT_TOKEN` | да | — | токен бота |
| `LLM_API_KEY` | да | — | ключ OpenAI-совместимого API |
| `LLM_BASE_URL` | нет | `https://api.openai.com/v1` | базовый URL API |
| `LLM_MODEL` | нет | `gpt-4o-mini` | модель |
| `LLM_MAX_ATTEMPTS` | нет | `5` | попыток на один LLM-разбор |
| `LLM_MAX_BACKOFF` | нет | `120` | макс. пауза между попытками, сек |
| `LLM_MAX_TOKENS` | нет | `50000` | max_tokens LLM-вызова (GLM; у OpenAI-моделей меньше) |
| `AUTHOR_TTL_DAYS` | нет | `90` | срок жизни обзора автора до фонового обновления |


## Как это работает

```
сообщение с YouTube-ссылкой
  → создаётся тред + статус «🎬 Смотрю субтитры…»
  → задача в очередь (1 LLM-запрос одновременно)
  → кеш в SQLite: разобрано раньше? → ответ мгновенно, без LLM
  → субтитры (ru → en → любые) с таймкодами
  → LLM: JSON-разбор по правилам prompts.yaml (ретраи при 429/сбоях) → в кеш
  → прогрессивный рендер: Кратко → Тезисы → Подробно (таймкоды)
  → форматирование под Discord + сплит на сообщения ≤1900 символов
  → отправка в тред; если Discord недоступен — буфер в БД
     и фоновая досылка раз в минуту
```

## Траблшутинг

| Симптом | Причина / решение |
|---|---|
| Бот молчит на ссылки | не включён Message Content Intent (см. настройку выше) |
| «⚠️ Нет права создать тред» | выдать право Create Public Threads |
| Саммари не приходит по одному каналу | тред под сообщением уже существует — бот переиспользует его (ошибка 160004 обрабатывается), проверьте архивные треды |
| В Docker нет соединения с Discord | `network_mode: host` обязателен в этом сетапе: трафик должен идти через стек хоста (DPI рвёт TLS к discord.com) |
| «У видео отключены субтитры» | у видео действительно нет доступных субтитров |
| Контейнер перезаписал мои правки кода | так работает self-update (`reset --hard`); правки — через git push |
